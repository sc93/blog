# 코드·콘텐츠 리뷰 지침

## 적용 시점

PR 생성 후 코드·콘텐츠·문서의 실제 변경을 리뷰하고 결과를 PR에 기록한다. PR 생성과 갱신 절차는 [Git 작업 절차](git-workflow.md)를 따른다.

## 현재 리뷰 기준

- 사용자가 제공할 상세 코드 리뷰 지침을 우선 적용한다. 아직 전달되지 않은 심사 규칙을 임의로 추가하지 않는다.
- 상세 지침이 전달되기 전에는 변경 목적과 실제 코드·콘텐츠를 대조해 오류와 회귀를 검토한다. 문서·글 작업도 해당 변경 범위에 맞춰 리뷰한다.
- 검토한 커밋 또는 변경 범위, 발견 사항과 검증 한계를 명시한다. 문제가 발견되지 않았다면 검토한 범위에서 발견 사항이 없다고 기록한다.
- 검증하지 않은 항목을 통과로 표시하지 않는다. AI 검토와 실제 GitHub 승인을 구분하고, 승인받지 않았다면 승인받았다고 표현하지 않는다.
- 리뷰 수정 후 검증은 [검증 지침](verification.md), 커밋·푸시·PR 갱신은 [Git 작업 절차](git-workflow.md)를 따른다.

## 추후 상세 지침

상세 리뷰 지침은 아직 전달되지 않았다. 전달받으면 이 문서에 반영한다.
